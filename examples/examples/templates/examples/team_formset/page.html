Team roster

A static Django formset with independent per-row reactivity — ADR-0003

Try it: set row 1's role to Admin — only that row reveals its admin note. Set a role to Owner/Admin and its email becomes required — again, per row. Typing in one row never affects another because each row binds to its own scoped signal.

Scope note: dynamic add/remove/reorder of rows is intentionally out of scope for now; this demonstrates static rows that behave independently.

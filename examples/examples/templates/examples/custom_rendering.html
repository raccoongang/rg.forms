The form (Python)

class TeamMemberForm(ReactiveForm):
    full_name = ReactiveCharField(
        label="Full name",
        placeholder="Jane Doe",
        autocomplete="name",
        autofocus=True,
    )
    role = ReactiveChoiceField(label="Role", choices=[...])
    email = ReactiveEmailField(
        label="Email",
        required=False,
        placeholder="jane@example.com",
        autocomplete="email",
        required_when="$role == 'owner' || $role == 'admin'",
    )

# In the view:
TeamFormSet = formset_factory(TeamMemberForm, extra=3)

Bring your own design system

The shipped rg_forms/field.html is a Bulma reference example. To adopt a host design system, override that one template with a thin dispatcher on widget_type that forwards the documented context (input_type, widget_attrs, field.html_name, field.id_for_label, and the reactive-attr set) to your own components. See the Custom Rendering guide in the docs.

Note: the per-row required_when indicator binds to a single $role signal shared across rows — the reactive signal layer is not yet formset-aware. Server-side submission (the focus of this example) round-trips correctly regardless.

Feature-flagged / permission-aware form

A server-owned signal drives the same rule on both sides — ADR-0002 §5

Try it: the plan tier and beta flag below are decided by the server via get_external_signal_values(). Flip them to watch both the client (visibility) and the server (validation) react identically. In this demo a query parameter stands in for real server policy so you can toggle it; in production these would derive from request.user / tenant / a flag service and never be client-controllable. The load-bearing guarantee either way: they are external signals — the server does not read them from the submitted form data, so a crafted form POST cannot set them.
